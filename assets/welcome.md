# Welcome to Markora

A Markdown workspace with local files, tabs, and a live document view.

## Start writing

Click any paragraph to edit its Markdown. Press **Escape** to render it again, or **Ctrl+Enter** to insert a paragraph below it.

Use **Source** for plain Markdown or **Split** to edit beside a preview. All views use the available workspace width.

## Your workspace

- Drag either sidebar divider to resize it.
- Use **Ctrl+O** to open a file and **Ctrl+S** to save.
- Use **Ctrl+Shift+P** to search commands.
- Use **Ctrl+D** for focus mode.

> Your Markdown is the document model. Formatting, editing, preview and saving all use the same content.

```rust
fn main() {
    println!("Hello, Markora!");
}
```

| Mode | Purpose |
| --- | --- |
| Live | Edit one block in the rendered document |
| Source | Edit the complete Markdown source |
| Split | Source and preview, side by side |
